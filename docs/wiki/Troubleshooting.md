# Resolver problemas

## O jogo não abre

Confira conexão, versão do Windows e registros do launcher. Teste a configuração automática de gráficos antes de combinar alterações.

## Uma configuração não faz efeito

Salvar uma FastFlag não comprova que o Roblox a aceita. Consulte Gráficos, reinicie o cliente e compare uma opção por vez.

## Ajuda

Use o Discord NRBlox Community: https://discord.gg/M8j8JnQSCx. Informe versão, sistema, passos e erro. Remova cookies, tokens e links privados antes de compartilhar registros.

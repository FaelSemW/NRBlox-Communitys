# Roadmap

Esta versão preserva o launcher nativo Windows e acrescenta identidade NRBlox Community, Discord próprio, wiki offline, MSAA 8x e presets experimentais de FPS.

Próximas etapas: perfis gráficos, melhores backups, canal de atualização próprio e avaliação de uma versão Linux.

Anti-AFK foi solicitado para uma etapa futura, mas não está implementado. Nenhuma função desta versão garante evitar desconexões por inatividade.

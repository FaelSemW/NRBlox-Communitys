Instalação

Baixe NRBlox-Communitys-v0.2.0-win-x64.exe em Releases e execute no Windows 10/11 de 64 bits. O runtime .NET está incluído, assim como a documentação offline.

O assistente instala o NRBlox em sua própria pasta. Os clientes Roblox e Studio são baixados separadamente quando necessários. O launcher não torna o motor Roblox open source.

O menu oferece iniciar Roblox, iniciar Studio e configurar preferências. As atualizações do cliente Roblox são separadas das atualizações do launcher. Novas versões NRBlox são distribuídas pelo repositório da comunidade.

Esta compilação não tem assinatura digital. Preserve backups antes de modificar arquivos do cliente.
